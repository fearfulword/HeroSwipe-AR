# 🦸‍♂️ HeroSwipe AR


## 💡 ¿De qué se trata?
La idea es súper simple: el programa ocupa mi cámara web para encontrar mi cara y ponerme máscaras encima (como la de Spiderman, Batman y esas cosas). 

Lo mejor de todo es que para cambiar de máscara no hay que tocar el teclado ni el mouse, solo usar la mano:
1. Si levanto dos dedos (el índice y el medio)...
2. Y muevo la mano hacia la izquierda rápido...
3. El programa se da cuenta y me cambia la máscara al instante.
